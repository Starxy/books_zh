# 数学、图表与版面保真

## 数学和编号

- 从本书实例确认章、节、附录、定理、定义、例、习题及框注的计数器关系。既可能共享章级序列，也可能按节或各环境独立；模板不能替代识别。
- PDF 重建时显式保存原公式号，未编号公式保持无编号。TeX 路线保留原编号机制和标签，核对合排后显示值。
- `\tag` 放在外层 `equation` 中、`aligned` 之外。长式按等号、运算或语义分组断行，保留括号配对、求和范围、上下标、量词、条件和正负号。
- 变量斜体，算子、多字母缩写和文字说明采用合适正体。因果 do 算子使用专用宏如 `\dox{X=x}`，不要占用 TeX 的 `\do`；若历史稿有带括号的调用，明确宏签名并核对 PDF 中是否实际显示 do。
- 在逐项核验记录中区分“同一编号的正文引用”与“新公式/图表定义”。原书的跳号、重印式和特殊号可能合法，保留并记录例外，不为强行连续而改原号。
- 原书疑式保留原貌并记录定位；必要的勘误解释用明确译注，与原文结论分开。

## 图表按内容角色处理

| 原对象 | 处理方式 | 验收重点 |
|---|---|---|
| 因果图、机制图、流程图、结构示意图 | 优先中文 LaTeX/TikZ 重绘 | 节点、边方向、双向/虚线、潜变量、面板、图例、图号与含义一致。 |
| 数据曲线、散点、实验图 | 保留原数据图形，或从可核验的矢量/印刷坐标重建 | 原始测量数据与印刷坐标分清，数值/比例/误差条/单位完整；不用随机数据拟合“相似外观”。 |
| 实验影像、照片、书前图版 | 保留与内容相关的原图，译排标题/注释 | 裁剪不损失含义；不要按“无法TikZ化”自动删除。改变范围须有依据并记录。 |
| 表格 | 按原行列与表头重排，长表可跨页 | 每个数值、符号、单位、脚注及缺失值符号对应；抽取失败先回看原页。 |
| 无法确认的部分 | 改善来源或定位局部核验；仍有缺口则记录未决 | 不补造箭头、表行、公式或照片内容；实质缺口未解决时不能标为完整成品。 |

每幅图独立或按面板设置唯一节点名前缀，避免同一 TikZ 图中重名覆盖。用坐标单位、版心宽度与字体大小共同控制图幅，不能把整体缩小到标签难读来消除溢出。
中文遮罩只盖原文字，保留线条、刻度、数据和照片主体。对原书用于展示模型局限的错误输出，译文说明其角色，不替模型纠正答案。

## 边注、框注与书籍结构

- Fine Point、Technical Point、学习目标、算法框等只在原书实际存在时复现；无此结构的书不套用其他教材的盒子。
- 边注是原书内容，不与阅读者电子批注混淆。根据实际单双面版式设置边注栏，逐页检查相邻边注、页底与正文的碰撞。
- `marginnote` 的常见垂直偏移写法为 `\marginnote{文字}[2.6cm]`；确认所用宏定义再套参数。不能让长度值误印成边注文字。
- 框内图表采用非浮动排版，如 `\captionof{figure}`；长框检查分页、标题可见性和编号。不要仅凭 tcolorbox 无报错判断标题存在。
- 分部页与分部引言只纳入一次；新重建工程由主入口组织。已有 TeX 工程保持其有效组织方式，不为统一目录强行搬动内容。
- 无编号序、引言、结语与有编号附录分别按原书处理；A/B/C 附录可使用适当的附录机制。检查目录、书签和页眉实际结果，而不从命令名称推断正确性。

## 版面问题的判断

检查公式截断、表格超宽、图注孤立、页眉大小写、缺字、框标题消失、页码与边注重叠，以及中文行内公式前后的异常空白。
Overfull、Underfull、字体回退都需看其来源和受影响页；没有“CJK 小于某点数一律忽略”的豁免。记录可接受的排版取舍及证据。
优先调整语句断行、数学断行、表列宽、图幅和浮动位置；避免用不可断行的大盒子或强行扩大页高把问题挤到页脚。

编辑 TeX 使用能保留原始文本的文件接口或正确转义的脚本。写后核查受影响段落和异常控制字符，正则替换注意反斜杠含义。不要为了工具写入方便先删除原文件；工具或平台的个别限制不能泛化成破坏性编辑规则。
