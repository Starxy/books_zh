# 书后材料、构建与交付

## 书前书后材料单独验收

逐项核对原书实际存在的书名页、出版信息、序、前言、符号说明、分部引言、致谢、附录、参考文献和索引是否已纳入译文。最后一个正文章节结束不代表整书结束。

**参考文献：** 有 BibTeX/Biber 源时保护文献键和书目信息，按工程命令生成；只有 PDF 时按版面和条目边界重建，跨页作者列表、断词、重音、DOI/URL 逐项核验。保留作者、题名、年份等可检索元数据，不把英文文献标题误算为漏译正文。断行连字符的增删依据原条目语义，不能只用下一行大小写决定。

**索引分两路：**

- 有可靠索引标记的源码：翻译可见词项，保留排序/交叉引用语义；正文和文献稳定后重新生成译本索引，检查条目定位页码与拼音/字母排序。
- 只有印刷索引：按栏、缩进和续行恢复主次层级，保留全部 locator 及 f/t 等标记。数字独立换行可能是条目尾部，不是页脚。若保留原版页码，在索引标题处明确说明，并提供英文与中文章节起始页对应表。章内用节号、图表号或搜索定位，不能按固定页码差或线性插值伪造中文索引页码。

核对书后材料的页数、条目数、首末条目及跨页接续是否有遗漏。原版索引与中文重建索引的选择在该书体例中写明；不另建书后材料核验记录。

## 构建依赖与稳定性

1. 从该书主文件、构建脚本和说明识别引擎、字体、宏包、文献、索引、图形和高亮依赖。默认使用已验证方案；Windows 中文字体不是跨平台保证。
2. 编译中间文件写入独立工作目录，必要时复制源码到系统临时目录；保留源资产的相对路径。`include` 的辅助文件目录也需存在。
3. 新建重建工程可用 XeLaTeX/ctex；已有工程按自身顺序运行。参考文献、索引工具按需执行，不把所有书固定为两遍 XeLaTeX。
4. 比较目录、交叉引用和索引相关辅助状态，直到页码稳定；设置有限上限（例如最多6—8轮），不稳定则诊断原因，不无限循环或宣称通过。
5. 编译错误、缺字、未解析引用/引文处理完毕；其余警告结合页面判断。跨章引用和整书分页需要编译整书后检查，单章结果不能替代。

固定 `.bbl` 或 minted 排版缓存有时是原版随附的构建依赖。可以保留为有说明的固定依赖，或整理为正式文献/代码排版源及明确映射，让构建器仅在临时目录恢复所需别名；不要直接删除或仅为改扩展名就声称已消除依赖。
在现有构建说明或资产元数据中维护资产来源、对应内容、维护方法和恢复流程。修改代码/文献后必须更新相应排版源。新旧方案需要干净复编及内容比对；教材示例代码无需执行。

## 完成前的检查

检查按本次改动涉及的内容执行，结果在回复中说明；除非用户明确要求独立报告，不为下表另建记录文件。

| 对象 | 检查内容 |
|---|---|
| 覆盖 | 按原书章、节及前后材料核对译文，包括脚注、习题、代码和框注；说明仍未补齐的内容和有意差异。 |
| 结构与技术内容 | 对照底本核对公式、图、表、定理、数学、拓扑、数据、标签与引用；保留原书合法跳号，需要解释的例外写入现有体例。 |
| 语言与视觉 | 术语按语境一致；中文可读且保持论证；查看新译或修改的公式、图表、框注、边注及可能溢出或重叠的版面，整书抽查章首页/目录/页眉/书后材料。 |
| 可重建与成品 | 从干净源码重建成功，目录与引用稳定；检查最终交付位置的实际 PDF，核对页数、全部书签、末页和哈希。 |

页数、文字量、编号正则命中数只用于发现疑点。A4 重排的中文译本可以显著短于英文小开本；既不能用固定页数比例验收，也不能以重排为由忽略内容缺口。
文字抽取不能证明图形正确；像素相同不能证明翻译语义完整。分别报告工具检查和人工/视觉核验范围，不把推测写成“全量通过”。

## 清理、归档与发布

- 正式源码保留正文、图表、数据、样式、字体许可、文献、高亮依赖及构建说明。测试入口、编译日志、辅助文件、阶段 PDF 和临时裁剪放工作目录。
- 清理前列出要移除的文件并区分依赖；重要旧稿先保留可恢复备份。Windows 删除/移动使用已核实属于目标范围的绝对路径。
- 本仓库根目录 `00_books/` 是完整中文 PDF 的唯一成品位置，每书保留当前完整的 `English_Book_Title_cn_translated.pdf`。新构建通过全部交付检查后再替换，失败不覆盖已有成品；阶段稿使用明确名称存于工作目录。
- 发布后核对成品 SHA-256 并更新根目录清单。所有纳入仓库的 PDF 通过 Git LFS 管理，原始 TeX 压缩包保留为底本证据。
- 复制后重新打开交付文件检查，防止修复后仍发布旧副本。多书压缩包按用户要求只放对应 PDF；逐文件验证名称和哈希，检查 ZIP 完整性。
- 同步 README、元数据、编译默认路径和所有当前说明。历史校对记录可保留原检查结论，需标明历史状态；路径变更后更新可用位置。
- 纯清理或路径改动时，保持成品 PDF 字节不变并核对哈希；影响构建输入的整理做干净复编，比较页数、书签、逐页文字。涉及图形或版面依赖变化时再比较相应渲染，必要时全部页面。
- 语义或版面已经修改时，预期成品会改变；说明具体改动及对受影响页面的检查结果，不要求与旧 PDF 像素相同。

最终回复只写实际完成的范围、成品位置、需要用户知道的检查结果和未决问题，不默认生成交付报告文件。指定范围仍有缺漏时保留阶段状态并继续已授权工作，不用一个可编译的截短版本结束整书任务。
