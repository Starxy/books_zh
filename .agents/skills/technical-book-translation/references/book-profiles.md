# 书籍类型、七书经验与术语

类型决定核验重点，不决定统一模板。一书可同时属于数学推导、数据图、代码与框注教材等多类；只应用有实际对应内容的规则。

## 七本书的不同体例

| 书籍及本次底本 | 主要类型 | 续译与校订时的关键约束 |
|---|---|---|
| Causality: Models, Reasoning, and Inference，第二版（2009） | 因果理论、图模型、结构方程 | 区分推断与推理；核对 do 算子、条件独立、潜变量和双向边；本书定理类共享编号以其实际章/节规则为准；结语及其他无编号材料不占新章号。 |
| Elements of Causal Inference: Foundations and Learning Algorithms（2017） | 理论与学习算法 | 既有工程用章级共享结果序列，代码片段也可能占结果号；习题号核对原文，不默认每章从1开始；附录A—C、参考文献和索引单独验收。 |
| Big Data in Omics and Imaging: Integrated Analysis and Causal Inference（2018） | 组学、影像与统计方法 | 公式和多级小节密集；清楚区分机制图与实验数据图；保留影像和数据本体，译排标签；章内附录、特殊公式号和原书疑误逐项记录。 |
| Targeted Learning in Data Science: Causal Inference for Complex Longitudinal Studies（2018） | 多作者统计方法、纵向因果研究 | 保留分部、章内假设和结果的原编号；核对估计目标、估计量、影响函数、时间下标及网络结构；各章术语在同一本书内协调，兼顾作者原有叙述差异。 |
| Foundations of Large Language Models，arXiv:2501.09223v4 源码 | 数学与工程结合的 LLM 教材 | v4 源码决定内容，旧v2 PDF不能替代；目录 Chapter7—Chapter12 对应书内六章；保留 BibTeX 文献元数据，中文索引在译本分页稳定后重建。 |
| Agentic Large Language Models，arXiv:2610.13455v1 源码 | 智能体、代码案例、模型架构 | 保护代码缩进、字符串、工具名、标签和按章文献；固定代码高亮及文献排版源属于依赖；保留进阶章标题的普通星号；图中错误答案可能是对照实验的一部分。 |
| Causal Inference: What If，2026年8月提供版 | 第二人称教学、边注与框注 | 保留作者对读者说“你”的口吻；Fine Point/Technical Point 分别维护本章序列；印刷边注完整译出；完整交付须检查参考文献和索引，不能只看正文最后一章。 |

上述条目是这批工程的经验，不是对未来不同版本的结构承诺。为新版本建立范围账本；不能仅凭“与旧版章数相同”判断完成。

## 按语境维护术语

术语优先级：用户明确用词 → 该书已确认术语表 → 对应领域惯用译法。发现冲突先核对语义；必要时写清范围和义项，不全库替换同形单词。

| 语境 | 本批次采用的约定与辨别方法 |
|---|---|
| 因果/统计推断 | causal inference＝因果推断；reasoning 通常是推理。潜在结局、反事实结局、可交换性、正值性、一致性、标准化、逆概率加权、目标试验依各书术语表。 |
| ACE 与 ATE | average causal effect 对应平均因果效应；遇 average treatment effect 单独核实概念与定译，不能把“平均处理效应”当全局禁词。 |
| 风险与估计 | hazard ratio 与 risk ratio 分别对应风险率比与风险比；estimand、estimator、estimate 分别为估计目标、估计量、估计值，不能混同。 |
| 图模型 | identifiability＝可识别性；dependence 与 correlation 区分相依和相关；collider、潜变量、干预节点与双向边按该书术语及图例。 |
| 靶向学习 | targeted learning、TMLE、nuisance parameter、clever covariate 等从目标书读取定译；不要把 What If 的用词未经核对覆盖到 Targeted Learning。 |
| 组学与影像 | 保持基因/蛋白名称、缩写、单位、矩阵维数、病理或影像标识；图内中文说明与英文符号一一对应。 |
| 本批次两本 LLM 书 | 用户已指定 inference 与 reasoning 均译“推理”；用“模型推理/推理阶段”与“推理能力/推理过程”等语境区分，必要时括注英文。该约定不外推到统计书。 |
| policy | 决策或强化学习中译“策略”，公共治理中译“政策”。token 在两本书既有工程中存在用户或书内用词差异，续译按目标书术语表。 |

建议术语字段：英文、中文、学科/义项、首次出现位置、需核对变体、理由、确认状态。
同一术语在每章首现可附英文，后续保持中文；算法名、模型名、人名、引文和书名按可检索性处理。
术语扫描先列候选上下文再修改，不能用“某词出现次数归零”替代语义检查。

## 语言与原例

理论和方法书采用克制的中文学术教材语体，保持假设与结论的强弱。作者直接对读者说话时保留相应人称，不能一律改“我们”。
普通问答、图内说明、注释性自然语言译中文；承担英语词元切分、语法、拼写、跨语言翻译或模型错误示例功能的字面字符串保留。代码中的可执行语句、API、变量和值保持原貌；只翻译不会改变示例含义的说明。
阅读代码是翻译工作，不意味着需要执行书中的安装、联网、训练、工具调用或服务启动命令。
