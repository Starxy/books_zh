# 按内容确定体例与选取译排参考

本 skill 适用于不同领域的技术书籍。先从目标底本识别内容和结构，再选择相关处理方法；一书可以同时具有下列多种特征，未列出的内容按其实际含义与原书结构处理。

## 从目标书确定体例

| 目标书实际包含的内容 | 需要确定的体例与核对重点 |
|---|---|
| 数学推导、定义、定理与习题 | 从原书实例确认编号是否共享、按章或按节重置，以及附录编号；保留假设、量词、符号约定、证明与习题。 |
| 机制图、数据图、实验影像与表格 | 区分表达关系的示意图与记录观测结果的图像；核对箭头、数值、单位、误差、图例和表格行列，按底本路线处理图中文字。 |
| 程序、算法、模型交互与错误示例 | 区分说明性语言和必须保留的字面字符串；保护代码结构、API、变量及示例故意保留的错误。 |
| 多作者章节、分部与章内附录 | 确认分部引言、各章术语义项和符号、章内文献与附录的组织方式，保留作者叙述差异。 |
| 教学问答、边注、框注与学习目标 | 保留实际人称及教学层次；确认各类框注是否独立编号、边注的阅读顺序和页边位置。 |
| 跨语言例句、命名规范与专业符号 | 判断外文承担的是叙述、语言分析对象还是规范性命名；保留承担专业含义的字形、大小写、上下标及原始字符串。 |

将本书采用的处理方式写入 `01_source/translation_style.md`，术语留在本书术语表。续译读取已有设置；换版时重新核对内容范围和结构，不能仅凭章数相同沿用旧版结论。

## 按语境维护术语

术语优先级：用户明确用词 → 该书已确认术语表 → 对应领域惯用译法。发现冲突先核对语义；必要时写清范围和义项，不全库替换同形单词。

以下是按义项判断的示例；新领域应从目标书及该领域用法建立术语，不要求套用这些术语条目。

| 语境 | 译法示例与辨别方法 |
|---|---|
| 因果/统计推断 | causal inference＝因果推断；reasoning 通常是推理。潜在结局、反事实结局、可交换性、正值性、一致性、标准化、逆概率加权、目标试验依各书术语表。 |
| ACE 与 ATE | average causal effect 对应平均因果效应；遇 average treatment effect 单独核实概念与定译，不能把“平均处理效应”当全局禁词。 |
| 风险与估计 | hazard ratio 与 risk ratio 分别对应风险率比与风险比；estimand、estimator、estimate 分别为估计目标、估计量、估计值，不能混同。 |
| 图模型 | identifiability＝可识别性；dependence 与 correlation 区分相依和相关；collider、潜变量、干预节点与双向边按该书术语及图例。 |
| 靶向学习 | targeted learning、TMLE、nuisance parameter、clever covariate 等从目标书读取定译；相近领域的其他译本只能辅助判断。 |
| 组学与影像 | 保持基因/蛋白名称、缩写、单位、矩阵维数、病理或影像标识；图内中文说明与英文符号一一对应。 |
| 模型运行与推理能力 | inference 指模型运行阶段时常译“推理”，reasoning 指推理能力或过程；结合原文分别写明“模型推理/推理阶段”与“推理能力/推理过程”，必要时括注英文。统计 inference 仍须按统计语境判断；单书用户约定只在其约定范围内使用。 |
| policy 与 token | policy 在决策或强化学习中常译“策略”，公共治理中常译“政策”；token 需区分语言模型、编译器或认证等语境，续译按目标书术语表。 |

建议术语字段：英文、中文、学科/义项、首次出现位置、需核对变体、理由、确认状态。
专业术语、译成中文的专有名词和文中明确命名的特殊概念，正文首次出现时保留“中文（English）”，如“局部性（Locality）”“多维异步性（Multidimensional Asynchronicity）”“倒金字塔工作流（Inverted Pyramid Workflow）”。原文带缩写时使用“中文（English Full Name，缩写）”；已直接保留英文原名的模型、算法或人名无需再套一层括号。

首次出现按正文的阅读顺序和具体义项判断，包括摘要及首次给出定义的说明；不把目录、页眉或图片里保留的英文算作正文已介绍。标题和表格保持简洁，英文可放在相应正文首次出现处。连续阅读的全文后续沿用中文或已介绍的缩写，不逐章重复；独立交付的章节按该交付范围重新判断。相同中文词用于不同专业义项时分别介绍，避免把普通动词“占据”误标为几何表征的occupancy。补注前核对已有括注，避免重复全称或嵌套括号。英文按指定底本及本书术语表填写，不凭相似译名补造原词。
术语扫描先列候选上下文再修改，不能用“某词出现次数归零”替代语义检查。

## 语言与原例

理论和方法书采用克制的中文学术教材语体，保持假设与结论的强弱。作者直接对读者说话时保留相应人称，不能一律改“我们”。
普通问答、可编辑源码中的图内说明、注释性自然语言译中文；TeX 工程未提供图表源码的成图按原样保留，具体见 [source-routes.md](source-routes.md)。承担英语词元切分、语法、拼写、跨语言翻译或模型错误示例功能的字面字符串保留。代码中的可执行语句、API、变量和值保持原貌；只翻译不会改变示例含义的说明。
阅读代码是翻译工作，不意味着需要执行书中的安装、联网、训练、工具调用或服务启动命令。
