本规范于2026-10-24根据本工作区七本书的译排、交付和目录整理经验编写。
这些工程提供可选择的参考成果，不限定本 skill 的学科、书目或可处理版次；流程由目标书的实际底本与结构决定。单书编号、术语和样式仍以该书资料为准。
用户指定参考来源为 Hermes 的 `technical-book-translation` skill，属于未随本仓库收录的外部参考资料。
已读取其 `SKILL.md`、`references/page-layout-fidelity.md`、`references/causal-inference-terms.md`、`references/backmatter-from-pdf.md` 及体例/校对模板。
这里重新组织流程和约束，运行本 skill 不依赖上述外部资料，也未复制其整套代码或原书文本。

## 保留的原则

术语先于正文；结构和数学保真；PDF 抽取结果回到原页核验；章节工作与整书集成分别验收；边注、框注、书前书后材料完整纳入；记录疑点和有意差异；检查最终交付位置的文件。示意图重绘只用于需要从 PDF 重建的路线；TeX 路线按下述用户要求保留原图表格式。

| 所有公式硬编码编号、所有定理按节共享 | PDF 重建与源码翻译分开；编号体系按目标书的实际环境与引用识别。 |

| 照片直接删除；表格抽取不全可用摘要替代 | 保留原书相关图像和数据；先回查原页，缺口明确记录，不能将压缩替代物当完整翻译。 |
| 固定编译两遍 | 按实际文献/索引依赖构建，比较相邻轮次的目录页码与引用结果，决定是否还需编译。 |

| 统一替换被列为禁词的译名 | 按语义和书内约定核对，避免混淆ACE/ATE、hazard/risk，以及统计inference和LLM inference。 |
| 固定开展并行、样章后等待许可 | 按 2026-11-06 用户要求改为按需并行，先准备术语表与上下文，具体分工和合并要求见 [协作流程](../SKILL.md#集成恢复与协作)。用户已授权整书且体例明确时持续推进，样章不额外制造审批门槛。 |
| 固定C0映射、忽略部分排版警告、删除原文件后重写 | 编码映射和警告按实际证据处理；保留原件并使用可靠文件编辑方式，避免平台经验被写成通用危险规则。 |

七书完成后的整理曾从清理后的源码独立复编并比较现有成品，共2,773页在当次页数、书签、逐页文字和96dpi渲染上相同。该结果说明那次目录清理保持了排版，不构成以后版本或所有译文语义的自动担保。
以后更新本 skill 时，把可重复的决策原则写入对应参考，把单书特例留在该书体例和校对记录，避免不断增加适用于所有书的绝对规则。
