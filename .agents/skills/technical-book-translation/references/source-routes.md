# 按底本选择流程

## 共同的底本清单

记录英文书名、作者、版次/修订日期、文件名、SHA-256、来源、用户要求的翻译范围，以及 PDF 页序与印刷页码的关系。目录名中的年份不能代替底本版本。
同一书的 PDF、TeX 压缩包和已有中译本可能分属不同版本；明确哪一份决定正文内容，其他材料仅作辅助。

建立“原书条目 → 中文文件/标签 → 状态 → 核验记录”的覆盖账本。粒度至少到节，书前书后材料单列；公式、图、表、定理类条目、习题、脚注和框注另外列编号或定位。
PDF 书签与印刷目录互相核对：书签可能缺漏、重复或层级不准，实际印刷结构才是 PDF 路线的最终依据。

## A. 指定版本有有效 TeX

适用：Foundations of Large Language Models 的 v4、Agentic Large Language Models 的 v1，以及其他已提供源码的书。

1. 保留原包和英文整书 PDF，按 TeX 章节组织译校，无需另存分章 PDF。检查解压路径，展开到独立目录，找真实主文件和活动 `input/include` 链，区分注释、条件分支、废弃草稿与实际内容。
2. 记录类文件、样式、字体、图像、文献、索引和代码排版依赖，先确认原工程的构建方式。现有中文工程继续沿用其验证过的入口。
3. 翻译有效正文、标题、图注、框注、算法说明和图内自然语言。保护宏命令、数学表达、标签、引用键、路径、URL、代码缩进和字面值。
4. 保留原有公式自动编号与 `label/ref/eqref/pageref`；用原版编号清单核对，不批量换成手写编号。短标题、计数器、星号等先辨认语义再调整。
5. 逐章比对有效数学、标签、图表、代码和引用清单；改动的图表与公式在中文 PDF 中目视检查。原版源码能够给出公式时，无需把整书逐页 OCR 一遍。

**本次经验：** `Chapter7`—`Chapter12` 可对应书内第1—6章；文件夹名不决定章号。源标题中的普通 `*` 可能表示进阶内容，并非无编号 `\chapter*`。固定文献和代码高亮排版源可能是原包不可缺少的依赖。

完成条件：有效源文件均有处理状态；构建依赖明确；章节与标签映射可核验；未拿旧版 PDF 补写新版源码中不存在的内容。

## B. 只有带文字层的 PDF

适用：本次 Causality、Elements of Causal Inference、Big Data in Omics and Imaging、Targeted Learning in Data Science、What If 的译排路线。

1. 清点书签、印刷目录、前后材料和页码标签；分章时保证原 PDF 页序无丢失、无重复。分部扉页与引言明确分配，不能在切章时漏掉。
2. 按页保留原始抽取文本。段前标注 `<<<PDFPAGE n>>>`，n 是原整书 PDF 的1基页序；若来源是分章 PDF，同时记录该页到整书的映射。
3. 多栏、页边注和脚注按版面坐标分别读取；表格以行列关系为准，不能直接采用文本提取的阅读顺序。阅读者后加的高亮、划线与批注不作为正文翻译；印刷边注属于原书内容。
4. 清洗连字、断行和控制字符时保留原始文本与处理记录。控制字符到括号的映射取决于具体 PDF 字体编码，抽样核实后只用于该底本；不能把另一书的 U+0000 等映射当通用标准。
5. 每个展示公式、每张表和每幅图对照原页渲染。疑难局部用高分辨率裁剪；PDF 裁剪坐标单位为 point，不是缩略图像素。
6. 重建中文 LaTeX。原书已编号公式可用显式 `\tag{原号}`；未编号公式保持无编号。定理、习题和附录按本书实际体系建立计数器或编号环境。

完成条件：章节提取与原页映射可回查；公式、图表和结构均有逐项核验记录；抽取失败的内容没有被无声跳过。

## C. 扫描 PDF 或局部文字层失效

1. 先检查图像清晰度、旋转、装订阴影、双页扫描和缺页；记录扫描页到印刷页的映射。
2. OCR 只产生草稿。保留页图、OCR 原文、校正文本和疑点定位；数学识别、表格识别和普通正文分别验收。
3. 正文逐页对照校正；公式、上下标、希腊字母、不等号、量词、否定、数据和箭头重点复核。英文语言模型补全出来的句子不能视为原文证据。
4. 模糊内容先尝试更清晰的同版来源或局部裁剪；仍无法识别时明确记录缺口。除用户另有约定，存在实质缺口的稿件保持未完成状态。

混合 PDF 按页采用 B/C，避免对可用文字层重复 OCR。不得以“只有两行被抽取”为理由断言原书只印两行表格；先看页图。

## 清点工具

`scripts/inspect_pdf.py` 以原整书页序记录书签与页面指标，可选抽取文本和渲染。低文字量仅提示扫描页、图版或空白页的可能性；它不自动判定缺页、书籍结构或译文完整性。
对已经核对的相同底本复用清点证据；换版后重新建立映射。
