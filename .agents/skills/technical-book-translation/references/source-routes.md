# 按底本选择流程

路线由指定版本的实际材料决定，适用于任意书名和领域。先确认是否有覆盖待译内容的有效 TeX，再判断 PDF 文字层是否可用；同一书可按章或页采用不同路线。已有译本仅用于参考处理方式，选取方法见 [book-profiles.md](book-profiles.md)，不能代替当前底本。

## 确认底本与范围

从现有 README、元数据和原文件确认英文书名、作者、版次/修订日期、文件名、SHA-256、来源、用户要求的翻译范围，以及 PDF 页序与印刷页码的关系；缺失信息补入相应现有文件。目录名中的年份不能代替底本版本。
同一书的 PDF、TeX 压缩包和已有中译本可能分属不同版本；明确哪一份决定正文内容，其他材料仅作辅助。

按节对应原书内容与中文文件或标签，分别检查书前书后材料，以及公式、图、表、定理、习题、脚注和框注；需要中断续做时，将未完成范围与对应位置写入同一个检查点，不另建覆盖账本或逐项核验报告。
PDF 书签与印刷目录互相核对：书签可能缺漏、重复或层级不准，实际印刷结构才是 PDF 路线的最终依据。

## A. 指定版本有有效 TeX

适用条件：已取得与指定版本对应、能够确认有效正文及依赖的 TeX 工程。若源码只覆盖部分内容，其余部分按实际 PDF 状态选择 B 或 C。

1. 保留原包和英文整书 PDF，按 TeX 章节组织译校，无需另存分章 PDF。检查解压路径，展开到独立目录，找真实主文件和活动 `input/include` 链，区分注释、条件分支、废弃草稿与实际内容。
2. 确认原工程的构建方式，保留其文档类、样式、纸张、页边距、栏数、标题层级、页眉页脚和文献体系。已有中文工程按这些整体特征判断是否偏离原模板，保留已确认且适合中文的排字设置。
3. 接入必要的中文字体与排字支持，从原有字号和间距试排，按实际阅读问题局部调整正文、标题、图注、脚注及段落、列表。保留原西文与数学字体，中文适配宜集中在单独的导言文件中；引擎兼容、字体选择及调整范围见 [版面参考](fidelity-and-layout.md)。中文长度与排字设置会改变分页，不强凑原页数。
4. 翻译有效正文、标题、图注、表题、框注和算法说明，保护宏命令、数学表达、标签、引用键、路径、URL、代码缩进和字面值。沿用公式环境与自动编号以及 `label/ref/eqref/pageref`；字号变化造成长公式超宽时可重新断行，数学内容与编号必须保持。
5. 图表以原包源码和资产为准。已有 TeX 表格、TikZ、PGFPlots 或原绘图工程时，只替换其中的自然语言，保留表格行列、线型、节点坐标、图幅、缩放与各图表的浮动位置选项。只有 PNG、JPEG、PDF 等成图而未提供图表源码时，直接使用原文件，图内文字不翻译；不从 PDF 提取图后加工，不裁剪、遮字或重绘。正文中的图注、表题仍按其 TeX 源码翻译。
6. 编译后对照原版核查整体模板、公式、标签、图表调用和引用，查看中文正文、标题、图注、表格及可能溢出的页面。无源码成图中保留的英文不属于漏译。中文适配所改的设置写入现有体例；会改变图表内容或原图布局的冲突需另行说明，不能借排字调整重绘原图。原版源码能够给出内容时，无需逐页 OCR。

核查源码时，章号以活动命令及编译结果为准，文件夹编号不决定章号。源标题中的普通 `*` 可能表示进阶内容，并非无编号 `\chapter*`。固定文献和代码高亮排版源可能是原包不可缺少的依赖。

完成条件：有效源文件均有处理状态；整体模板与图表布局沿用原工程，中文字体和间距经过页面检查；无图表源码的原图文件内容未改动；章节与标签映射可核验；未拿旧版 PDF 补写新版源码中不存在的内容。

## B. 只有带文字层的 PDF

适用条件：指定版本没有覆盖该内容的有效 TeX，PDF 文字层可用于提取正文；多栏、公式或表格的阅读顺序仍需回到原页判断。

1. 清点书签、印刷目录、前后材料和页码标签；分章时保证原 PDF 页序无丢失、无重复。分部扉页与引言明确分配，不能在切章时漏掉。
2. 按页保留原始抽取文本。段前标注 `<<<PDFPAGE n>>>`，n 是原整书 PDF 的1基页序；若来源是分章 PDF，同时记录该页到整书的映射。
3. 多栏、页边注和脚注按版面坐标分别读取；表格以行列关系为准，不能直接采用文本提取的阅读顺序。阅读者后加的高亮、划线与批注不作为正文翻译；印刷边注属于原书内容。
4. 清洗连字、断行和控制字符时保留原始文本与处理记录。控制字符到括号的映射取决于具体 PDF 字体编码，抽样核实后只用于该底本；不能把另一书的 U+0000 等映射当通用标准。
5. 每个展示公式、每张表和每幅图对照原页渲染。疑难局部用高分辨率裁剪；PDF 裁剪坐标单位为 point，不是缩略图像素。
6. 重建中文 LaTeX。原书已编号公式可用显式 `\tag{原号}`；未编号公式保持无编号。定理、习题和附录按本书实际体系建立计数器或编号环境。

完成条件：提取的章节能定位到原页；公式、图表和结构已对照原页核对；抽取失败的内容没有被无声跳过。

## C. 扫描 PDF 或局部文字层失效

适用条件：指定版本没有覆盖该内容的有效 TeX，且页面为扫描图像，或文字层缺失、乱码及遗漏使其不能用于正文提取。

1. 先检查图像清晰度、旋转、装订阴影、双页扫描和缺页；记录扫描页到印刷页的映射。
2. OCR 只产生草稿。保留页图、OCR 原文、校正文本和疑点定位；数学识别、表格识别和普通正文分别验收。
3. 正文逐页对照校正；公式、上下标、希腊字母、不等号、量词、否定、数据和箭头重点复核。英文语言模型补全出来的句子不能视为原文证据。
4. 模糊内容先尝试更清晰的同版来源或局部裁剪；仍无法识别时明确记录缺口。除用户另有约定，存在实质缺口的稿件保持未完成状态。

混合 PDF 按页采用 B/C，避免对可用文字层重复 OCR。不得以“只有两行被抽取”为理由断言原书只印两行表格；先看页图。

## 清点工具

`scripts/inspect_pdf.py` 以原整书页序记录书签与页面指标，可选抽取文本和渲染。低文字量仅提示扫描页、图版或空白页的可能性；它不自动判定缺页、书籍结构或译文完整性。
对已经核对的相同底本复用清点证据；换版后重新建立映射。
