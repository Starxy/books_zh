# 保留原版式的中文字体与段落排版

用于初次建立中文样式或调整已有样式；续译沿用已确认设置。字体和字号/行距范围依据用户提供的《arXiv 中文学术论文阅读字体建议（2026 更新版）》整理，均为试排建议，没有适合所有书籍和设备的唯一配置。该文档不规定分栏、页边距或页面布局；下述保留模板、段落和 TeX 接入方法是针对本 skill 的补充。来源见 [provenance.md](provenance.md)。

## 保留什么，调整什么

- 有有效 TeX 时，保留原文档类和样式、纸张、版心、栏数、章节组织、标题层级、页眉页脚及编号机制。中文支持和字体设置尽量集中在一个适配导言文件，避免逐章覆盖样式。仅有 PDF 时依原页识别这些特征，再建立中文工程。
- 先接入中文字体、标点和断行，保留原正文标称字号试排；中文过密、细笔画不清或上下行相碰时，再调整中文字体、字号或实际基线距离。已有中文译本若已适合阅读，不为套用下表而重新排版。
- 原西文、数学和代码字体默认保留。用户参考文档中的 IBM Plex、STIX Two 等组合是重选字体时的候选，不要求替换原模板字体或改用 `unicode-math`。原字体缺字或与所用引擎不兼容时，针对具体问题选择替代并核对符号。
- 中文会改变行数和分页，不追求原页数或逐行对应。表格超宽、边注碰撞等先检查译文断行与局部字号；若仍需改变版心、分栏或图表布局，说明具体冲突及拟改范围，按已有授权处理，不能仅为符合建议数值重设计整书。图表处理边界仍按 [版面参考](fidelity-and-layout.md)。

## 字体的选择和分工

优先顺序为用户已指定样式、目标书已确认体例、按阅读用途试排。新项目未指定时，以与原模板气质相近的中文字体起步：衬线正文可试宋体，无衬线正文可试黑体；以屏幕阅读为主要用途时优先比较黑体表现，也保留宋体选择。简体译本选 SC/CN 字形版本；繁体译本按目标地区选择字形。下表不是必须安装的清单。

| 用途 | 可选中文字体 | 试排时看什么 |
|---|---|---|
| 宋体正文、PDF 精读或打印 | 思源宋体 / Noto Serif SC；文渊宋体可作替代 | 小字号的细横画、复杂汉字、与原西文和行内数学的视觉大小。 |
| 黑体正文、屏幕阅读或原无衬线样式 | 思源黑体 / Noto Sans SC；文渊黑体可作替代 | 笔画和字腔是否清楚、密集术语的辨认、连续多段的阅读感受。 |
| 偏好楷体的读者或少量中文强调 | 霞鹜文楷屏幕阅读版，或已选用的楷体 | 与密集公式和符号的协调；不用作所有书的默认正文。 |
| 标题、图注、脚注 | 沿用本书选定的中文宋体/黑体及原有层级 | 标题可用黑体或真实较粗字重；辅助文字不因缩小而丢失上下标与标点。 |
| 含中文的代码和等宽说明 | 更纱黑体的等宽变体，或与原西文等宽字体配套的中文字体 | 中文与 ASCII 的列宽、缩进、框线；不替换可执行字符串。 |

字体实际名称、字重与覆盖范围以安装文件为准；不能把商品名直接当 TeX 可识别的字族名。只安装/配置本书所需字体，将来源、版本和所需字重写入现有构建说明；随源码分发字体时一并核对并保留其许可。缺字或字重缺失时明确选择替代，不依赖无提示的系统回退。

### 正常、加粗与斜体

- 正文从 Regular（通常为 400）开始。局部强调选实际存在的 Medium/Semibold/Bold；例如思源黑体静态版通常用 Medium 500 或 Bold 700，不假定其有独立 Semibold 600。避免把整篇正文改成细体或粗体来弥补字号问题。
- 原文的语义强调可由真实较粗字重或少量楷体表达，汉字不机械倾斜。设定中文 `ItalicFont`、`BoldFont` 等映射前，检查该模板的 `\emph`、`\textit` 和定理正文是否承担不同角色；不要把整段斜体定理一律变成粗体。
- 数学变量、拉丁学名等规范性斜体仍保留斜体；单位、算子等正体仍保留正体。中文强调映射不改变西文与数学字体命令。粗斜体所承载的强调层级也应可辨，不启用模拟粗斜作为通用方案。

## 字号与实际行距

下表只在原设置需要调整或新建工程没有已确认设置时使用。以正文实际 `\baselineskip` 除以标称字号表示行距比；它是两行基线的距离，不是字框之间额外增加的空白。

| 用途 | 正文试排字号 | 实际基线距离 / 字号 |
|---|---|---|
| 一般 PDF 精读、打印 | 10.5–12 pt，可从 11 pt 试起 | 1.4–1.6，可从 1.5 试起；11 pt 对应约 16.5 pt 基线距离。 |
| 原模板较紧凑、需保留其内容密度 | 9.5–10.5 pt | 1.3–1.5；小于 10 pt 时特别检查复杂汉字、脚注和上下标。 |
| 图注、表注、脚注 | 先保留原层级；需放大时可比较正文的 85%–95% | 可从 1.4–1.6 试起，按各环境实际内容调整，不全局套正文倍率。 |
| 多行标题 | 沿用原层级字号 | 需要调整时可比较 1.2–1.45，单行标题主要看上下留白。 |

这些范围不是下限或强制目标；例如原 10 pt 模板若已清楚可读，可以保留。屏幕缩放和字体字面大小都会影响显示效果，应在预期缩放比例或打印尺寸检查。

用户参考文档的黑体 16–18 px、行高 1.55–1.75，宋体 17–19 px、行高 1.6–1.85，是可重排屏幕阅读的建议；不要直接当作固定页面 PDF 的 TeX 参数。CSS px、PDF point 和 TeX pt 的单位与显示条件不同。

`\linespread{1.5}` 或 `\setstretch{1.5}` 会在文档类已有行距上再施加倍率，并不表示“基线距离等于字号的 1.5 倍”。先读取原类和当前正文的字号、`\baselineskip` 及已有倍率，只选一种有效调节途径；不要叠加 ctex、setspace 与手工字号的倍数。用文档类支持的设置或局部 `\fontsize{字号}{基线距离}\selectfont` 时，核对最终值及切换环境后的恢复。含高分式的行可能需要更大距离，不能硬压回表中数值。

## 段落、标点与局部布局

- 保留段落语义边界；英文源码的普通换行不是新段落。中文正文通常两端齐排，使用中文排版支持处理禁则、标点压缩和中西文间距，不手工插空格、`\\` 或负间距凑行。
- 原模板采用首行缩进时，可从两个汉字宽试排，段间不另加一整行；原模板采用无缩进加段距时，保留该方式，必要时从约 0.3–0.5 个正文基线距离试排段距。这些是段落适配建议，不是原参考文档的数值。不要同时堆叠大缩进和大段距。
- 章/节标题后首段、定理、引文、列表、图注和脚注沿用各自的缩进规则，不全局强制两字缩进。列表层级和编号样式保留，逐项检查换行后的悬挂缩进；段距改变后检查列表和公式上下留白是否被再次放大。
- 中文正文使用相应中文标点；数学、代码、URL 和原样保留的英文字符串按各自语法处理。检查行首句末标点、行末开括号，以及汉字与英文/行内公式之间的空白；优先用中文宏包处理，局部调整需有具体页面问题。
- 继续使用原页眉页脚、边注栏和浮动选项。若 `\flushbottom` 拉出异常段间空白，先检查浮动体和分页约束；确有需要时可用 `\raggedbottom` 允许自然页底。长 URL/英文术语采用能保留文本及链接的断行方式，不靠扩大页高、统一缩小全页或改栏数解决。

## 在原 TeX 工程中接入

先查看原引擎和已加载的中文/字体宏包，在现有设置上修改，避免重复加载。仅为加入中文不应把原类改成 `ctexbook`。

- **XeLaTeX：** 若只需中文字体、标点和中西文间距，可用 `xeCJK`，保留原类与西文字体；若工程采用 ctex 的统一中文配置接口，可考虑 `ctex` 宏包的 `scheme=plain, heading=false, fontset=none`，显式配置中文字体，按需翻译目录等名称，再检查原标题与间距是否受到影响。这些选项各有作用，不能据此推断所有模板的版式都不变。
- **LuaLaTeX：** 沿用已验证的 LuaTeX 中文支持，或采用 ctex 对该引擎的支持；按该方案配置中文字体，不照搬 xeCJK 专用命令。
- **其他原引擎：** 先确认其中文方案与宏包依赖；需要改引擎时，核对原字体、数学、绘图及文献的兼容性。引擎迁移本身不构成更换文档类和布局的理由。

机制依据：[CTeX 文档与源码](https://github.com/CTeX-org/ctex-kit/tree/master/ctex)、[xeCJK 文档](https://ctan.org/pkg/xecjk)。字体资源可从 [思源宋体](https://github.com/adobe-fonts/source-han-serif)、[思源黑体](https://github.com/adobe-fonts/source-han-sans)、[文渊字体](https://github.com/takushun-wu/WenYuanFonts)、[霞鹜文楷屏幕阅读版](https://github.com/lxgw/LxgwWenKai-Screen)、[更纱黑体](https://github.com/be5invis/Sarasa-Gothic)查阅。

## 试排后的决定

选目标书实际包含的连续正文、章首页、多行标题、行内/展示公式、图表、脚注，以及存在时的边注、框注、代码页面；查看汉字与西文字号、真实字重、强调区别、缺字、断行和溢出。调整后比较原模板的纸张、版心、栏数和信息层级，解释确实需要改变的部分。将采用字体、字号、实际基线距离、段落设置及其源码位置写入该书现有 `translation_style.md`，构建依赖写入 `README_build.txt`，不另建样式核验报告。
