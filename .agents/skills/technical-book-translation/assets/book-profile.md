# 书籍译排体例

使用方式：复制到目标书 `01_source/translation_style.md`，依据底本填写。下列空项是待调查字段，不是默认决定；删去不适用项目。

## 底本与范围

- 英文名、作者、版次、修订日期：
- 主底本文件、来源、SHA-256：
- 路线（TeX / 文本PDF / 扫描 / 混合）及版本差异：
- PDF整书页序、印刷页码、分章页码映射：
- 授权范围及原书章节与中文文件的对应关系：
- 主入口、活动章节、图形/文献/索引依赖：

## 语言与编号

- 术语表位置、用户定译、重点义项：
- 作者人称、叙述语体、英文例句/代码保留规则：
- 公式编号与引用机制：
- 定理/定义/例/习题等共享或独立计数器：
- 分部、无编号章节、附录、脚注及特殊号：
- 原书实际框注、边注类型与编号：
- 原文档类、样式、纸张、版心、标题层级和页眉页脚（TeX 路线参考）：
- 阅读用途；中文正文、标题、等宽及强调字体的实际字族/字重；保留的西文和数学字体：
- 原字号与采用字号、正文实际基线距离（pt）、对应设置位置；图注/脚注等局部设置：
- 段落首行缩进、段间距、中文标点与断行设置；原布局需调整时的具体原因：
- 中文支持方式、字体来源/版本及构建依赖（具体安装方法写入构建说明）：
- 图表源码与成图的区分；可译文字及保留的原图：
- 参考文献处理及索引定位规则：

## 构建与交付

- 编译命令、引擎、字体、宏包、文献/索引工具：
- 工作目录与构建临时目录：
- 当前完成范围、最后成功构建与检查点位置：
- 正式成品路径（完整稿放入仓库根目录00_books）：
- 本书需要检查的内容及交付要求：
- 原书疑误、待确认对象与处理依据：

## 协作（按需并行时填写）

- 集成者、共享文件和各执行者可编辑文件：
- 分工范围、章入口归属、跨章依赖及需顺序处理的内容：
- 分工前共用的术语表与体例、相关义项及首次出现位置：
- 交接的原文与已有译文位置、前置定义/符号/假设及相邻段落：
- 新增或改译术语的提交、确认、通知及已译内容修订方式：
- 合并时需复核的上下文衔接、术语用法和跨章引用：
