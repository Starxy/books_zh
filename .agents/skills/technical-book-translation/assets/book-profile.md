# 书籍译排体例

使用方式：复制到目标书 `01_排版源码/翻译体例说明.md`，依据底本填写。下列空项是待调查字段，不是默认决定；删去不适用项目。

## 底本与范围

- 英文名、作者、版次、修订日期：
- 主底本文件、来源、SHA-256：
- 路线（TeX / 文本PDF / 扫描 / 混合）及版本差异：
- PDF整书页序、印刷页码、分章页码映射：
- 授权范围、完整结构清单与覆盖账本位置：
- 主入口、活动章节、图形/文献/索引依赖：

## 语言与编号

- 术语表位置、用户定译、重点义项：
- 作者人称、叙述语体、英文例句/代码保留规则：
- 公式编号与引用机制：
- 定理/定义/例/习题等共享或独立计数器：
- 分部、无编号章节、附录、脚注及特殊号：
- 原书实际框注、边注类型与编号：
- 图表分类与中文化方法：
- 参考文献处理及索引定位规则：

## 构建与交付

- 编译命令、引擎、字体、宏包、文献/索引工具：
- 工作目录与构建临时目录：

- 正式成品路径（完整稿放入仓库根目录00_books）：
- 核验清单和交付标准：
- 原书疑误、待确认对象与处理依据：
