## 交稿顺序

1. 对照 metadata 书签核对章内节序，全文翻译所有正文、章首导言、脚注、表格、例子、推导、证明、注记及延伸阅读。保留作者署名、机构、邮箱和章 DOI，页眉、出版社重复页脚无需逐页重现。
2. 按原文每 1—2 节写一个 chNNa.tex、chNNb.tex 等；chNN.tex 仅用 \input 汇总。第一分文件只出现一次 \chapter{中文章名}，随后 \chapterauthors{姓名} 与 \chapteraffiliations{译出的机构及原邮箱}。不要在章内加入 \part 或 \setcounter{chapter}。
3. 每个展示公式、表格与图必须渲染英文对应页核对。原始 PDF 的阅读批注、划线、高亮不进入译稿；渲染前在内存删除 annots。不修改原文件。
4. 源文有编号的公式使用 \tag{原编号}，无编号的使用 \[...\]。多行公式用 aligned，tag 放在 end{aligned} 后。原文编号优先于任何通用自动规则。原文数学式若缺少或多出可见括号，仍保持印刷可见符号并记录疑点；TeX 配对用普通定界符、\lbrace/\rbrace 或 \left.、\right. 等不可见定界符解决，不补入原书没有的可见数学括号。
5. 本书定理和引理各自计数，不能套用其他书的混合计数。最稳妥的方式是 \begin{bookresult}{定理}{5.1}...\end{bookresult}，依原文逐条填名称和编号；证明用 proof。原文的假设标签 (A1) 等照录。
6. 重绘关键图用 TikZ 中文标签，保留面板、节点、箭头方向、虚线、双向边和原图号。数据图不可虚构坐标或数据；精确保留原图数据层、用中文重做轴标签和图例也可，但需在报告说明。每图检查实际成品 PNG。
7. 编译两遍，修复 ! 错误、缺字和超宽公式；检查一页图表及一页普通正文。自测章节编号由隔离测试驱动设置为 N-1，交付章节正文不设计数器。
8. 固定报告保存到 work/targeted_learning/reports/chNN.json：中文 PDF 页数、文件清单、逐节覆盖情况、图/表/公式清单、未解决项及原因、新术语 EN→ZH、原书编号异常、编译检查结果。未解决项不能以完成的口吻掩盖。

## 行文与版式

- 中文学术教材口吻，使用“我们”，调整长句语序，不删减论据、限定条件或历史实例。正文保留文献作者、年份与书名。历史叙述不擅自改写为今天的情况。
- 用户已指定 targeted learning＝靶向学习；targeted minimum loss-based estimation＝靶向最小损失估计。原文 targeted maximum likelihood estimation 译为靶向极大似然估计，两者不混同。每章首现写中文（英文及缩写）。
- 只保留原书已有框体，第 1 章有无标题的强调框；不额外制造 Fine Point / Technical Point 框。强调框用 sourcebox；原文的定理不自动加框。
- 表格数字逐格核对，原书只给部分结果则如实保留部分，绝不补造数据。
- 图表依原书连续编号；跨节引用写“第 3.2 节”“式 (3.19)”“图 3.1”。只在图表顺序确与原书不一致时向总审报告，不自行重排。
- 可用宏见 preamble.tex。缺少的宏在本章用 \providecommand 定义，名称应带章号以免冲突；不要定义 \do。do 算子用 \dox{X=x} 或 \doxp(X=x)。TikZ 公用 causal/vtx/lat/ed/edd/bid 样式可直接使用。
- 同一图多面板节点使用各自前缀；图尺寸用 x/y 单位而非盲目 scale。框内插图用 captionof 而非 figure 浮动体。
- 不用 shell 重定向或转义不稳定的字符串写 TeX。用 apply_patch 的原始字符串，或 Python 中以 \ 占位后替换为 chr(92)；编辑后检查控制字符。
- 最终交稿清除自测驱动和其辅助文件（仅自己隔离目录中的 test_chNN.*）；报告和用于 QA 的 PNG 可以保留。共享工程不放自测残留。
